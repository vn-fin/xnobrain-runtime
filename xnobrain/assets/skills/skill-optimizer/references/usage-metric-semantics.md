# Usage metric semantics

Requested is intent, loaded is an observed successful `SKILL.md` read, and
run-associated deduplicates by run/skill/digest. Reference reads are successful
attributed reference loads. Tool invoked/completed/failed are tool-hook outcomes;
multiple and unattributed provenance must remain explicit. These counters are not
billing or proof that guidance caused quality. Historical requests are estimated and
must leave unmeasured fields unknown.
